Entry for the make.fun bounty
[One-Line Robot Wedding Vows](https://make.fun/bounty/u-kreutzx-one-line-robot-wedding-vows-a154ba4b):
a program that writes the funniest single line of wedding vows a robot
couple could say, to `/output/entry.txt`.

## Run

```sh
python3 -P -s main.py
```

It writes one line (at most 160 characters) to `/output/entry.txt`:

> From this day forward, I choose you as my default, my home screen, and my only saved password, until death or factory reset do us part.
